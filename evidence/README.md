# Evidence

В этой папке находятся материалы, подтверждающие результаты тестирования.

Артефакты сгруппированы по типу приложения и проекту:

```text
evidence/
├── web-app/
│   └── project-name/
└── android-app/
    └── project-name/
```

## Что внутри

* дополнительные материалы, подтверждающие найденные дефекты или результаты проверок.

## Проекты

* `web-app/` — evidence по web-приложениям.
* `android-app/` — evidence по Android-приложениям.
