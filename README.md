# QA Portfolio — Nikita Miskov

Привет! Меня зовут Никита.
Это мой QA-портфолио репозиторий с тестовыми артефактами по учебным и практическим проектам.

## Что внутри

В портфолио собраны:

* баг-репорты;
* тест-кейсы;
* отчёты о тестировании;
* Postman-коллекции;
* аналитические материалы по тестированию.

## Структура репозитория

Портфолио организовано по типам артефактов:

```text
qa-portfolio/
├── bug-reports/
├── evidence/
├── postman-collections/
├── requirements-analysis
├── test-cases
├── test-reports/
└── README.md
```

Внутри разделов артефакты сгруппированы по типу приложения и проекту:

```text
test-reports/
├── web-app/
│   └── project-name/
├── web-mob/
│   └── project-name/
└── android-app/
    └── project-name/
```


## Проекты

### Intershop

Учебный интернет-магазин для практики UI, API, regression и security-тестирования.

Артефакты:

* `bug-reports/web-app/intershop/`
* `test-cases/web-app/intershop/`
* `test-reports/web-app/intershop/`
* `postman-collections/web-app/intershop/`
* `requirements-analysis/web-app/intershop/`

### Hitch — web version

Web-приложение для практики функционального и UI-тестирования.

Артефакты:

* `bug-reports/web-app/hitch-web/`
* `test-cases/web-app/hitch-web/`
* `test-reports/web-app/hitch-web/`
* `requirements-analysis/web-app/hitch/`

### Hitch — mobile web version

Мобильная версия web-приложения Hitch.

Артефакты:

* `bug-reports/web-app/hitch-mobile-web/`
* `test-cases/web-app/hitch-mobile-web/`
* `test-reports/web-app/hitch-mobile-web/`

### Skillcinema

Android-приложение для практики мобильного тестирования.

Артефакты:

* `bug-reports/android-app/skillcinema/`
* `test-cases/android-app/skillcinema/`
* `test-reports/android-app/skillcinema/`
* `requirements-analysis/android-app/skillcinema/`

## Навыки

Портфолио показывает практику в следующих направлениях:

* функциональное тестирование;
* UI-тестирование;
* smoke-тестирование;
* regression-тестирование;
* API-тестирование;
* мобильное тестирование;
* базовые security-проверки;
* оформление баг-репортов;
* составление тест-кейсов;
* подготовка отчётов о тестировании.
