# Test Cases

В этой папке находятся тест-кейсы и чек-листы по QA-проектам.

Артефакты сгруппированы по типу приложения и проекту:

```text
test-reports/
├── web-app/
│   └── project-name/
├── web-mob/
│   └── project-name/
└── android-app/
    └── project-name/
```

## Что внутри

* функциональные тест-кейсы;
* UI-проверки;
* smoke-тесты;
* regression-проверки;
* мобильные проверки.

## Проекты

* `web-app/` — тест-кейсы для web-проектов.
* `web-mob/` — тест-кейсы для мобильных версий сайтов.
* `android-app/` — тест-кейсы для Android-приложений.
