# Test Reports

В этой папке находятся отчёты о тестировании и итоговые рекомендации по QA-проектам.

Артефакты сгруппированы по типу приложения и проекту:

```text
test-reports/
├── web-app/
│   └── project-name/
├── web-mob/
│   └── project-name/
└── android-app/
    └── project-name/
```

## Что внутри

* отчёты о проведённом тестировании;
* краткие итоги по найденным проблемам;
* рекомендации по готовности продукта;
* аналитические материалы по результатам проверок.

## Проекты

* `web-app/` — отчёты по web-приложениям.
* `web-mob/` — отчёты по мобильным версиям сайтов.
* `android-app/` — отчёты по Android-приложениям.
