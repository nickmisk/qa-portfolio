# Requirements Analysis

В этой папке находятся материалы по анализу требований для QA-проектов.

Артефакты сгруппированы по типу приложения и проекту:

```text
requirements-analysis/
├── web-app/
│   └── project-name/
└── android-app/
    └── project-name/
```

## Что внутри

* анализ требований;
* уточнения по логике работы функций;
* заметки по рискам и возможным проверкам.

## Проекты

* `web-app/` — анализ требований для web-приложений.
* `android-app/` — анализ требований для Android-приложений.
